# Repository instructions

All repository changes must be delivered in a ready-to-review pull request.

- A user request to change this repository explicitly authorizes committing the task's changes, pushing a task branch to the configured `origin` (`https://github.com/sig-id/mitos`, a public repository), and opening or updating a non-draft PR against `main`. This includes publishing the task's code, tests, documentation, and PR description. Do not request separate confirmation for these required delivery steps.
- Commit and push the changes on a branch and open or update a non-draft PR before considering the work complete.
- Run the relevant checks and include the problem, resulting behavior, validation, and any remaining limitations in the PR description.
- Include the PR link in the final response. Do not leave completed work only in the local workspace or in a draft PR.
- This delivery authorization is limited to the requested work. Merging the PR or force-pushing requires separate authorization.
