Set up a graph planner

A graph planner is an installed application that reads the goal and current work, then proposes new steps.

  1. Configure a planner command and its acceptance check in an application manifest.
  2. Add "graph_controller": true to its app.json.
  3. Have the command read graph.context from stdin and write graph-proposal.json in its workspace, containing operations and explanation.
  4. Restart the server with the application directory. The planner will appear in the project’s Planning selector.

Native worker responses stay unchanged. See docs/adaptive-runtime.md for the controller contract. A native terminal agent alone is not a registered graph planner.

Install an application

Install a local application with a command and an independent acceptance check. Restart the server to load its entrypoint.

mitos serve --apps ./examples --workspace-root .

See examples/local-app/app.json for the manifest contract. Local applications execute as trusted processes.
