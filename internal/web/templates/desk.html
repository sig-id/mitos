Attention & breakpoints

The topic board stores shared context. Attention requests deliver urgent context. A breakpoint waits for explicit acknowledgments; commands already running may finish.

How supervision works

The supervisor receives your project profile and objective when it starts. It discovers installed agents and launches visible Mitos sessions with assigned tasks. Workers publish evidence on the topic board and notify the supervisor. The supervisor reviews the result and coordinates the next step.

Pi receives native steering messages. Claude receives context and pause checks at prompt/tool boundaries. Linked Codex conversations receive queued context, with cooperative pause handling. Other agents use the Mitos inbox. These are trusted local processes; free-form project rules are agent instructions, not filesystem confinement.
